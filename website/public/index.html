Features

  • One-click attach

    Injects into the running Roblox client and holds the session across teleports.

  • Real editor

    Monaco — the VS Code engine — with Lua highlighting, tabs, find and .lua save/load.

  • Script hub

    Search the built-in library, open a script into a tab, run it. Your workspace sits underneath.

  • Key system

    Lifetime, yearly, monthly or custom-duration keys, validated online and revocable at any time.

  • Auto-exec

    Mark a workspace script to run itself the moment attach succeeds.

  • Small footprint

    One executable. No bundled runtimes, no telemetry, nothing left in the registry.

Setup

  1. 01

    Download and extract

    Grab the zip below and extract it to its own folder — don’t run it from inside the archive.

  2. 02

    Run as administrator

    Right-click Casium.exe → Run as administrator. First launch asks for your key; free keys are handed out in the Discord.

  3. 03

    Attach

    Open Roblox, join any experience, wait for your character to load, then press Attach.

  4. 04

    Execute

    Paste Lua into the editor or load something from the hub, and press Execute. That’s it.

FAQ

Is Casium free?

Yes. The client costs nothing; access runs through licence keys with a duration (lifetime, one year, one month or custom). Keys are checked against casium.top on launch.

How do I get a key?

In the Discord. Paste it into the client on first launch — it’s saved locally, so you only enter it once per machine.

My key says expired, but I just got it.

Check your Windows clock: expiry is compared against system time, and a drifted clock fails validation. Otherwise the key may be mistyped or revoked — keys are case-sensitive.

Windows Defender removed the file.

Injection tools get flagged heuristically. Restore it from Defender’s protection history and exclude the Casium folder. Verify your download against the SHA-256 we publish with each release.

Which games work?

Casium targets the standard Windows Roblox client. Games with their own client-side protections may block execution — that’s per-game, not a broken install.

Mac, mobile or Microsoft Store client?

No. Windows 10/11 x64 with the web-download Roblox client only, and no plans for other platforms.
