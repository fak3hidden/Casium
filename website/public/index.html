FAQ

Is Casium free?

Yes. Access runs through licence keys with a duration — lifetime, one year, one month or custom — checked against casium.top on launch. Free keys are handed out in the Discord.

How do I get a key?

In the Discord. Paste it into the client on first launch; it’s saved locally, so you only enter it once per machine.

My key says expired, but I just got it.

Check your Windows clock — expiry is compared against system time. Otherwise the key may be mistyped or revoked; keys are case-sensitive.

Windows Defender removed the file.

Injection tools get flagged heuristically. Restore it from protection history and exclude the Casium folder. Verify downloads against the SHA-256 published with each release.

Which games work?

Casium targets the standard Windows Roblox client. Games with their own client-side protections may block execution — that’s per-game, not a broken install.

Mac, mobile or Microsoft Store client?

No. Windows 10/11 x64 with the web-download Roblox client only.

Windows 10 / 11 x64 · some antiviruses flag executors as false positives — add an exclusion for the Casium folder, never disable protection entirely.
