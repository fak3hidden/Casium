02 / Scripting

Written for people who read
their own code.

The loader, the key gate and the hub API are all plain Lua. Copy a snippet, paste it into a tab, run it — nothing is hidden behind a UI you can’t script around.

Casium exposes a small, stable surface: authenticate a key, load a hub script, and keep a session alive. Everything else is your Lua.

  • Server-side key checks. The client posts the key to /api/validate and gets back validity, expiry and remaining time — revocation takes effect immediately.
  • Standard request stack. request, HttpGet and loadstring behave the way every hub script expects.
  • No obfuscation games. Scripts run as written; the executor doesn’t rewrite your source before handing it to the VM.
  • Integrating the core? The BubbleAPI bridge used by the WPF client is documented in the last tab — attach, execute, save, clear. 
-- casium loader · paste into a tab and execute
local Hub = loadstring(game:HttpGet(
    "https://casium.top/loader.lua"
))()

Hub:Auth(CASIUM_KEY)
Hub:Load("Infinite Yield")
-- key gate: what the client runs on launch
local Http = game:GetService("HttpService")

local res = request({
    Url    = "https://casium.top/api/validate",
    Method = "POST",
    Headers = { ["Content-Type"] = "application/json" },
    Body   = Http:JSONEncode({ key = CASIUM_KEY })
})

local data = Http:JSONDecode(res.Body)
if not data.valid then
    return warn("[casium] key rejected: " .. (data.reason or "unknown"))
end

print("[casium] ok · expires", data.expiresAt or "never")
-- hub api surface
local Casium = require(game.ReplicatedStorage.Casium)

Casium.Notify("Attached", "core online")   -- toast in-client
Casium.IsAttached()                          -- boolean
Casium.Session()                             -- { key, expiresAt }
Casium.Run("autofarm.lua")                   -- from workspace

for _, script in Casium.Hub() do
    print(script.name, script.version)
end
// BubbleAPI bridge used by the WPF client
BubbleAPI.Internal.Inject();                  // attach
BubbleAPI.Internal.Execute(Editor.Text);     // run current tab
BubbleAPI.Internal.SaveTextAsLua();           // export .lua
BubbleAPI.Internal.ClearCode();               // reset editor

// window chrome
BubbleAPI.Internal.MinimizeWindow();
BubbleAPI.Internal.ExitApplication();

04 / FAQ

Questions, answered plainly.

Anything missing? Ask in the Discord — support is handled there, not by email.

The client is free to download. Access is gated by a licence key: keys are issued with a duration (lifetime, one year, one month, or a custom length) and are checked against casium.top every time the client starts.
Keys are distributed through the Discord. Paste the key into the client on first launch; it’s saved locally afterwards so you only enter it once per machine.
Check your Windows clock — key expiry is compared against your system time, and a drifted clock will fail validation. If the clock is correct, the key may have been revoked or mistyped; keys are case-sensitive and follow the casium-xxxxx-xxxxx-… format.
Injection tools are heuristically flagged by most vendors. Restore the file from Defender’s protection history and add an exclusion for the folder you keep Casium in. We publish a SHA-256 checksum with every release so you can verify what you downloaded.
Casium targets the standard Windows Roblox client. Games running under Hyperion/Byfron anti-cheat or with their own client-side protections may block execution — that is a per-game limitation, not a broken install.
No. Casium is Windows-only (10 and 11, x64) and requires the web-download Roblox client. There are no plans for other platforms.
